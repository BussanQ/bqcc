# DecentID 概念模型（先读这一页）

> 觉得「概念太多」？其实**核心只有 3 个**，其余全是可选叠加。这一页用大白话讲清整个模型，看完再去翻命令手册或协议细节都不迟。

---

## 一句话

**DecentID = 一个完全由你自己掌控、不依赖任何平台的数字身份。**

没有注册服务器，没有账号密码，没有谁能替你注销它。

---

## 3 个核心概念（去掉任何一个都不成立）

### 1. 身份 = 一把密钥

你的身份就是一对密钥。由它算出一个固定的**身份码**：

```
身份码（DID） = did:p2p:<root 公钥的哈希>
```

- **为什么需要**：没有中心服务器发号，身份只能来自你自己持有的密钥。
- **大白话**：身份码就像你的「数字指纹」，第一次生成后**永远不变**——改名、写内容、甚至换掉主控密钥都不会变。

### 2. 连续性 = 一条签名的变更链

每次改动（加设备、撤设备、换主控密钥、更新内容…）都记成一条**带签名的变更记录**，一条接一条，只能往后追加。验证方拿到后**从头回放、逐条验签**，重算出当前状态。

- **为什么需要**：身份要能「演化」（换手机、丢设备），又不能被人伪造历史。
- **大白话**：像一本只能往后写、每页都盖章的账本——别人能照着重算一遍确认没被改过。

### 3. 登录 = 证明你握着密钥

验证方给你一道随机「**题目**」，你用设备密钥**签名作答**；验证方用你的**公开名片**核对签名。

- **为什么需要**：证明「这是我」而不用把密钥或密码交出去。
- **大白话**：对方出题、你当场签名、对方验签通过——全程不联网账号系统，也拿不到你的私钥。

> 这 3 件事就是 DecentID 的全部地基。下面的都可以不用。

---

## 可选扩展（在核心之上叠加，不用时完全可以忽略）

- **内容 / 记忆**：给身份挂内容。可以**公开**（明文）或**只有我能看**（加密保存）。
- **他人背书（attestation）**：别人给你出具一张「我认识 TA」的凭证，作为独立对象挂在你名下。
- **点对点分享（P2P）**：把你的**公开名片**和公开内容直接发给对端、或从对端取回，不经过任何中心服务器。
- **加密备份**：用一个口令把身份导出成加密文件，换设备/重装时凭口令恢复。

## 术语对照表（全项目以此为准）

代码和协议细节里会出现一些「行话」，对照如下：

| 行话 | 大白话 | 说明 |
|---|---|---|
| DID | 身份码 | 你的全局身份编号，永久不变 |
| root / device / encryption key | 主控 / 设备 / 加密密钥 | 主控管权限、设备管日常签名、加密管私有内容 |
| event | 变更记录 | 变更链上的一条带签名记录 |
| replay / 回放验证 | 重算核对 | 从头逐条验签、重建当前状态 |
| SignedIdentityState | 公开名片 | 给验证方的、不含私钥的身份状态 |
| keyring（本地身份文件） | 钥匙串 | 本地保存的私钥集合，**绝不外发** |
| challenge-response | 登录验证 | 出题—签名—验签 |
| memory（object / manifest） | 内容（对象 / 目录） | 一条内容；目录指向一组内容 |
| CID | 内容指纹 | 由内容算出的标识，内容变指纹就变 |
| attestation | 他人背书 | 第三方给你的凭证 |
| publish / resolve | 发布 / 取回 | 点对点对外提供 / 从对端拉取 |
| multiaddr | 网络地址 | 对端节点的地址 |

## 分层图（核心很小，外圈都可选）

```
┌──────────────────────────────────────────────┐
│  界面层    简单模式（大众） · 高级控制台（开发者）   │  ← 默认只看简单模式
├──────────────────────────────────────────────┤
│  应用层    app.Service（把下面的能力包装好）         │
├──────────────────────────────────────────────┤
│  ★ 核心    身份(DID) · 变更链+回放 · 登录验证       │  ← 真正的地基，只有这 3 个
├──────────────────────────────────────────────┤
│  扩展      内容/记忆 · 他人背书 · 加密备份           │  ← 可选，不用就忽略
├──────────────────────────────────────────────┤
│  传输      P2P（发布 / 取回）                       │  ← 可选，且与验证完全分离
└──────────────────────────────────────────────┘
```

记住一句话：**「身份是一把密钥，历史是一条签名链，登录是一次签名」**——其余都是锦上添花。
